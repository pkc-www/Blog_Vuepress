1. 网络方程的建立 / Formulating Network Equations

两类约束 / Two Constraints (P3–P4)

电力网络 = 元件 element + 连接 connection，对应两类相互独立的约束：

  • 元件特性约束 Element characteristic constraint：无源线性元件满足欧姆定律 U˙b=ZbI˙b\dot U_b=Z_b\dot I_bU˙b​=Zb​I˙b​，与元件如何连接无关。
    English: Each passive linear branch obeys Ohm's law regardless of how it is connected.
  • 网络拓扑约束 Network topology constraint：把元件看作支路，只考察连接关系，满足基尔霍夫定律
    KCL: ∑k∈jik=0\text{KCL: }\sum_{k\in j} i_k=0KCL: ∑k∈j​ik​=0（节点），KVL: ∑k∈luk=0\text{KVL: }\sum_{k\in l} u_k=0KVL: ∑k∈l​uk​=0（回路），与元件参数无关。
    English: Treating elements as branches, KCL/KVL describe connectivity only and do not depend on element characteristics.

等值电路 / Equivalent Circuit (P5–P6)

  • 线路、变压器均用 π 型标幺等值电路（见第二章稳态模型）。
  • 定义节点注入功率 nodal injected power（净功率）：发电机注入为“+”，负荷吸收为“−”，即 S˙i=S˙Gi−S˙Di\dot S_i=\dot S_{Gi}-\dot S_{Di}S˙i​=S˙Gi​−S˙Di​。
  • 把节点注入功率暂时看作注入电流源 I˙i\dot I_iI˙i​，网络就成为“线性无源网络 + 节点电流源”，可以用电路原理中的节点电压法求解。
    English: Nodal net injections are temporarily modeled as current sources, giving a linear network solvable by nodal analysis.

节点电压方程 / Nodal Voltage Equations (P7–P8)

节点电压法 Nodal voltage method：已知节点注入电流，求节点电压。以三节点网络为例，对每个节点列 KCL：

{I˙1=U˙1y10+(U˙1−U˙2)y12+(U˙1−U˙3)y13I˙2=U˙2y20+(U˙2−U˙1)y12+(U˙2−U˙3)y23I˙3=U˙3y30+(U˙3−U˙1)y13+(U˙3−U˙2)y23\begin{cases} \dot I_1=\dot U_1y_{10}+(\dot U_1-\dot U_2)y_{12}+(\dot U_1-\dot U_3)y_{13}\\ \dot I_2=\dot U_2y_{20}+(\dot U_2-\dot U_1)y_{12}+(\dot U_2-\dot U_3)y_{23}\\ \dot I_3=\dot U_3y_{30}+(\dot U_3-\dot U_1)y_{13}+(\dot U_3-\dot U_2)y_{23} \end{cases} ⎩⎨⎧​I˙1​=U˙1​y10​+(U˙1​−U˙2​)y12​+(U˙1​−U˙3​)y13​I˙2​=U˙2​y20​+(U˙2​−U˙1​)y12​+(U˙2​−U˙3​)y23​I˙3​=U˙3​y30​+(U˙3​−U˙1​)y13​+(U˙3​−U˙2​)y23​​

整理成矩阵形式：

I˙n=YnU˙n\dot{\mathbf I}_n=\mathbf Y_n\dot{\mathbf U}_n I˙n​=Yn​U˙n​

  • I˙n\dot{\mathbf I}_nI˙n​：节点注入电流列向量；U˙n\dot{\mathbf U}_nU˙n​：节点电压列向量（相对参考节点 O，通常为大地）；Yn\mathbf Y_nYn​：节点导纳矩阵 nodal admittance matrix。
  • 独立方程数 = nnn = 除参考节点 O 以外的节点数。
  • 定义节点阻抗矩阵 Zn=Yn−1\mathbf Z_n=\mathbf Y_n^{-1}Zn​=Yn−1​，则 U˙n=ZnI˙n\dot{\mathbf U}_n=\mathbf Z_n\dot{\mathbf I}_nU˙n​=Zn​I˙n​。
  • 核心思想：支路特性（元件约束）与拓扑信息（连接约束）全部“打包”进网络矩阵 Yn\mathbf Y_nYn​ 或 Zn\mathbf Z_nZn​ 中。
    English: Both branch characteristics and topology are contained in the network matrix.

2. 节点导纳矩阵 / Nodal Admittance Matrix YnY_nYn​

定义与元素取值 / Definition (P9)

  • 自导纳 Self-admittance YiiY_{ii}Yii​：与节点 iii 相连的所有支路导纳之和（含对地支路）。
  • 互导纳 Mutual-admittance YijY_{ij}Yij​：节点 iii、jjj 之间支路导纳的负值，Yij=−yijY_{ij}=-y_{ij}Yij​=−yij​。
  • 若 iii、jjj 之间无支路：Yij=0Y_{ij}=0Yij​=0。实际电网每个节点只与少数几个节点相连，所以 YnY_nYn​ 中绝大多数元素为零。

三节点网络的 YnY_nYn​ (P13)：

Yn=[y10+y12+y13−y12−y13−y12y20+y12+y23−y23−y13−y23y30+y13+y23]\mathbf Y_n= \begin{bmatrix} y_{10}+y_{12}+y_{13} & -y_{12} & -y_{13}\\ -y_{12} & y_{20}+y_{12}+y_{23} & -y_{23}\\ -y_{13} & -y_{23} & y_{30}+y_{13}+y_{23} \end{bmatrix} Yn​=​y10​+y12​+y13​−y12​−y13​​−y12​y20​+y12​+y23​−y23​​−y13​−y23​y30​+y13​+y23​​​

令 U˙j=1\dot U_j=1U˙j​=1、其余节点电压全为 0（即其余节点全部短路接地），则

[Y1j⋮Ynj]=Yn ej⟹Yij=I˙iU˙j∣U˙k=0, k≠j\begin{bmatrix}Y_{1j}\\ \vdots\\ Y_{nj}\end{bmatrix}=\mathbf Y_n\,\mathbf e_j \quad\Longrightarrow\quad Y_{ij}=\left.\frac{\dot I_i}{\dot U_j}\right|_{\dot U_k=0,\ k\ne j} ​Y1j​⋮Ynj​​​=Yn​ej​⟹Yij​=U˙j​I˙i​​​U˙k​=0, k=j​

  • YjjY_{jj}Yjj​：在节点 jjj 加单位电压、其余节点短路时，从节点 jjj 注入网络的电流。例：Y11=y12+y13+y10Y_{11}=y_{12}+y_{13}+y_{10}Y11​=y12​+y13​+y10​。
  • YijY_{ij}Yij​：此时节点 iii 的注入电流。因为电流是从节点 iii 流向地（流出网络），所以为负：Y21=−y12Y_{21}=-y_{12}Y21​=−y12​，Y31=−y13Y_{31}=-y_{13}Y31​=−y13​。
  • 只有与 jjj 直接相连的节点才有电流，这正是 YnY_nYn​ 稀疏的物理原因：YnY_nYn​ 只反映局部（相邻）信息。
    English: YijY_{ij}Yij​ is the current injected at node iii when a unit voltage is applied at node jjj and all other nodes are short-circuited; only adjacent nodes respond.

一条连接 iii、jjj 的支路 lll（导纳 yly_lyl​）只影响 YnY_nYn​ 中 i,ji,ji,j 行列交叉的 4 个元素：

YnY_nYn​ 的性质 / Features of YnY_nYn​ (P14–P16)

  1. n×nn\times nn×n 对称复数方阵：Yij=YjiY_{ij}=Y_{ji}Yij​=Yji​（网络无源、互易）。若含移相变压器，对称性被破坏。
  2. 稀疏 Sparse：大量零元素。大规模电网需采用稀疏存储（只存非零元及其位置）和稀疏矩阵技术，否则存储量与计算量按 n2n^2n2 增长。
  3. 奇异性 Singularity：
    • 若没有对地支路，由 ΔYl\Delta\mathbf Y_lΔYl​ 的结构，YnY_nYn​ 每一行元素之和为 0，即 Yn1=0\mathbf Y_n\mathbf 1=\mathbf 0Yn​1=0，所以 YnY_nYn​ 奇异——物理上，所有节点电压同时抬高一个常数，不会产生任何电流，电压没有“参考”。
    • 只要连通网络中存在对地支路（如线路充电电容、并联电抗器），YnY_nYn​ 一般非奇异。
  4. 对角占优 Diagonally dominant：当各支路阻抗性质相同时（如都是感性），

    ∣Yii∣≥∣∑j≠iYij∣|Y_{ii}|\ge\Big|\sum_{j\ne i}Y_{ij}\Big| ∣Yii​∣≥​j=i∑​Yij​​

    • 含线路充电电容时：对地电纳 jB/2jB/2jB/2 为容性，与感性串联导纳 −j/x-j/x−j/x 符号相反，会抵消 YiiY_{ii}Yii​ 的一部分，因此对角占优可能不再严格成立；不过高压线路充电电纳远小于串联电纳，通常仍近似成立。
      English: Shunt charging capacitance has opposite sign to inductive series admittance, so strict diagonal dominance may fail.

3. 节点阻抗矩阵 / Nodal Impedance Matrix ZnZ_nZn​

定义 / Definition (P17)

Zn=Yn−1,U˙n=ZnI˙n\mathbf Z_n=\mathbf Y_n^{-1},\qquad \dot{\mathbf U}_n=\mathbf Z_n\dot{\mathbf I}_n Zn​=Yn−1​,U˙n​=Zn​I˙n​

ZiiZ_{ii}Zii​：节点 iii 的自阻抗 self-impedance；ZijZ_{ij}Zij​：节点 iii、jjj 之间的互阻抗 mutual-impedance。

物理意义：开路参数 / Physical Meaning: Open-Circuit Parameters (P18)

令 I˙j=1\dot I_j=1I˙j​=1、其余节点注入电流全为 0（即其余节点全部开路），则

Zij=U˙iI˙j∣I˙k=0, k≠jZ_{ij}=\left.\frac{\dot U_i}{\dot I_j}\right|_{\dot I_k=0,\ k\ne j} Zij​=I˙j​U˙i​​​I˙k​=0, k=j​

  • 自阻抗 ZjjZ_{jj}Zjj​：从节点 jjj 与参考节点看进去的网络等值总阻抗（戴维南等值阻抗）——这也是短路计算中节点短路电流 I˙f≈U˙j(0)/Zjj\dot I_f\approx \dot U_j^{(0)}/Z_{jj}I˙f​≈U˙j(0)​/Zjj​ 的来源。
  • 互阻抗 ZijZ_{ij}Zij​：单位电流从 jjj 注入时，在节点 iii 产生的电压，是总阻抗 ZjjZ_{jj}Zjj​ 上“分压”得到的一部分，可写为 Zij=1ηZjjZ_{ij}=\dfrac{1}{\eta}Z_{jj}Zij​=η1​Zjj​（η≥1\eta\ge1η≥1 为分压比）。
  • 在连通网络中，单位电流注入任一节点，所有节点电压都会变化，所以 ZnZ_nZn​ 一般是满阵，反映的是全局信息。
    English: ZjjZ_{jj}Zjj​ is the Thevenin impedance seen at node jjj; ZijZ_{ij}Zij​ is the open-circuit voltage at node iii for a unit current at jjj.

ZnZ_nZn​ 的性质 / Features of ZnZ_nZn​ (P20–P21)

  1. 有对地支路时是 YnY_nYn​ 的逆，为 n×nn\times nn×n 对称复数方阵；无对地支路时 YnY_nYn​ 不可逆，ZnZ_nZn​ 不存在。
    • 此时需指定一个参考节点（给定其电压），把它从未知量中去掉，YYY 和 ZZZ 都降为 (n−1)×(n−1)(n-1)\times(n-1)(n−1)×(n−1) 阶。
      数学上：去掉一行一列后矩阵满秩；物理上：电压必须有参考点才有确定值。这与后面潮流计算中的平衡节点是同一思想。
  2. 连通网络为满阵 Full matrix；不连通网络为分块对角矩阵。
  3. 对角元最大：无源网络中 ∣Zii∣≥∣Zij∣|Z_{ii}|\ge|Z_{ij}|∣Zii​∣≥∣Zij​∣。对元件的要求：网络无源，且各元件阻抗性质相同（例如全为感性），否则可能出现 LC 谐振式的电压放大，使互阻抗大于自阻抗。

形成方法 / Formulation Methods (P21)

  • 求逆法：Zn=Yn−1\mathbf Z_n=\mathbf Y_n^{-1}Zn​=Yn−1​。
  • 支路追加法 Add-branch method：从 1 个节点 1 条支路开始，逐条追加支路并修正 ZZZ，直至形成整个网络（不作考试要求）。
  • 基本要求：会用定义（开路试验）求简单网络的 ZnZ_nZn​。

4. 功率方程（潮流方程）/ Power-Flow Equations

为什么需要潮流方程 / Why (P23–P24)

潮流计算 = 电力网络 + 给定边界条件 → 潮流分布。

  • 节点电压方程 I˙n=YnU˙n\dot{\mathbf I}_n=\mathbf Y_n\dot{\mathbf U}_nI˙n​=Yn​U˙n​ 要求已知节点注入电流。
  • 但实际边界条件是复功率：发电机按功率出力调度，负荷按功率消耗；注入电流事先并不知道（它依赖于待求电压）。
  • 所以要把方程中的已知量由电流换成功率，建立“功率（已知）—电压（待求）”的关系，即潮流方程。
    English: Actual boundary conditions are complex powers, not currents, so the nodal equations must be rewritten in terms of power.

推导：变量替换 / Derivation by Variable Replacement (P25)

节点注入复功率 S˙i=Pi+jQi=U˙iI˙i∗\dot S_i=P_i+jQ_i=\dot U_i\dot I_i^{*}S˙i​=Pi​+jQi​=U˙i​I˙i∗​，所以

I˙i=Pi−jQiU˙i∗\dot I_i=\frac{P_i-jQ_i}{\dot U_i^{*}} I˙i​=U˙i∗​Pi​−jQi​​

代入第 iii 行节点电流平衡 I˙i=∑j=1nYijU˙j\dot I_i=\sum_{j=1}^{n}Y_{ij}\dot U_jI˙i​=∑j=1n​Yij​U˙j​：

Pi−jQi=U˙i∗∑j=1nYijU˙j(i=1,2,…,n)P_i-jQ_i=\dot U_i^{*}\sum_{j=1}^{n}Y_{ij}\dot U_j\qquad(i=1,2,\dots,n) Pi​−jQi​=U˙i∗​j=1∑n​Yij​U˙j​(i=1,2,…,n)

  • 物理本质：由“节点电流平衡（线性）”变为“节点功率平衡”——每个节点注入的功率等于经各支路流出的功率之和。
  • 方程含 U˙i∗U˙j\dot U_i^{*}\dot U_jU˙i∗​U˙j​ 乘积项，是非线性复数方程，必须迭代求解。
    English: The power-flow equation is a nodal power balance; it is nonlinear because of the products of voltages.

潮流方程的特点小结 / Summary of Features

特点说明
物理本质每个节点的功率平衡
非线性含电压乘积 / 三角函数，必须迭代求解
稀疏第 iii 个方程只含与 iii 相邻节点的电压（继承自 YnY_nYn​）
相角平移不变需要相角参考
功率不能全给定网损由电压决定、事先未知，所以全网至少要留一个节点的功率作为未知量（下一讲：节点分类与平衡节点）

5. 专题思考 / Special Topic (P32)

问题：交流电网为何采用 50/60 Hz？低频输电有何影响及其价值？

以下为思考提纲（非课件原文）：

  • 频率偏高的代价：线路电抗 X=ωLX=\omega LX=ωL 与充电无功 QC∝ωCU2Q_C\propto\omega C U^2QC​∝ωCU2 都随频率增大，线路传输极限 Pmax⁡≈U1U2XP_{\max}\approx\dfrac{U_1U_2}{X}Pmax​≈XU1​U2​​ 下降，集肤效应、涡流损耗增大，长距离输电不利。
  • 频率偏低的代价：变压器、电机铁芯截面与 1/f1/f1/f 成正比（U≈4.44fNBmAU\approx4.44fNB_mAU≈4.44fNBm​A），设备体积、用材增大；照明闪烁明显。50/60 Hz 是设备成本与输电能力之间的历史折中。
  • 低频输电 LFAC（如 50/3 Hz）：电抗降为 1/3，输送容量和距离提高；电缆充电电流显著减小，适合海上风电送出和城市电缆网。代价是两端需变频换流设备、低频侧变压器体积增大。国内已建成柔性低频交流输电示范工程。
