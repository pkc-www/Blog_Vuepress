第11章 模拟和数字滤波器

Avalanche2026/3/29大约 7 分钟信号与系统信号处理课程笔记

1. 滤波器概念与不失真传输

滤波器是一个系统，信号经过该系统后，各个频率分量的幅值按特定规律放大或缩小，相位按特定规律移位。
根据处理信号的不同，滤波器分为模拟滤波器与数字滤波器。

信号的无失真传输条件：
对于连续系统，为实现无失真传输（输出 ra(t)r_a(t)ra​(t) 仅是输入 ea(t)e_a(t)ea​(t) 乘以常数增益并延迟时间 t0t_0t0​，其波形形状不发生改变），有：

ra(t)=Kea(t−t0)r_a(t) = K e_a(t - t_0) ra​(t)=Kea​(t−t0​)

对两边取傅里叶变换：

Ra(ω)=KEa(ω)e−jωt0R_a(\omega) = K E_a(\omega) e^{-j\omega t_0} Ra​(ω)=KEa​(ω)e−jωt0​

所以系统传输函数（频率响应）必须为：

Ha(ω)=Ke−jωt0H_a(\omega) = K e^{-j\omega t_0} Ha​(ω)=Ke−jωt0​

由此可见，实现信号无失真传输的条件是：

  • 系统的幅频特性为常数：∣Ha(ω)∣=K|H_a(\omega)| = K∣Ha​(ω)∣=K
  • 系统的相频特性为一条穿过原点的直线：φ(ω)=−ωt0\varphi(\omega) = -\omega t_0φ(ω)=−ωt0​（线性相位）

2. 理想模拟滤波器与物理可实现性

理想的滤波器在频域具有垂直的过渡带边沿，通带内幅频响应为常数，阻带内幅频响应为 0。

物理可实现性（因果性限制）：
理想低通滤波器的频率响应在频域中是矩形窗，其对应的冲激响应为非因果的 Sa(t)Sa(t)Sa(t) 函数（即在 t<0t < 0t<0 时也有值），这意味着在激励加入之前系统就会产生输出。因此，理想滤波器物理上是不可实现的。

佩利-维纳 (Paley-Wiener) 准则：
从频域判断一个系统物理可实现的充要条件为：

∫−∞∞∣ln⁡∣Ha(ω)∣∣1+ω2dω<∞\int_{-\infty}^{\infty} \frac{|\ln |H_a(\omega)||}{1 + \omega^2} d\omega < \infty ∫−∞∞​1+ω2∣ln∣Ha​(ω)∣∣​dω<∞

以及必要条件（能量有限）：

∫−∞∞∣Ha(ω)∣2dω<∞\int_{-\infty}^{\infty} |H_a(\omega)|^2 d\omega < \infty ∫−∞∞​∣Ha​(ω)∣2dω<∞

这导致了物理可实现系统在频域上的两个限制：

  1. 幅频特性 ∣Ha(ω)∣|H_a(\omega)|∣Ha​(ω)∣ 不能在任何一个有限的连续频率段上恒为零（否则对数积分为 −∞-\infty−∞）。
  2. 幅频特性的衰减速度不能超过指数阶。

希尔伯特 (Hilbert) 变换：
物理可实现的因果系统，其频率响应的实部 Har(ω)H_{ar}(\omega)Har​(ω) 与虚部 Hai(ω)H_{ai}(\omega)Hai​(ω) 存在相互约束关系（通过希尔伯特变换约束）。这表明幅频和相频特性是不可能独立设计的，在设计时必须进行取舍。

3. 巴特沃兹 (Butterworth) 滤波器

巴特沃兹滤波器是一种幅频特性在通带内最大平坦的滤波器。

  • 幅频特性：

    ∣Ha(jω)∣=11+(ωωc)2n|H_a(j\omega)| = \frac{1}{\sqrt{1 + \left( \frac{\omega}{\omega_c} \right)^{2n}}} ∣Ha​(jω)∣=1+(ωc​ω​)2n​1​

    其以分贝表示的衰减为：

  • 设计实例：
    已知设计指标为：通带截止频率 ωp\omega_pωp​，通带最大衰减 αp\alpha_pαp​；阻带截止频率 ωs\omega_sωs​，阻带最小衰减 αs\alpha_sαs​。
    1. 建立方程组：

4. 数字滤波器

对于模拟信号，频率 ω\omegaω 可以从 −∞-\infty−∞ 变化到 +∞+\infty+∞。而对于数字信号，复指数序列 ejθne^{j\theta n}ejθn 的频率具有以 2π2\pi2π 为周期的周期性：

  • θ=2kπ\theta = 2k\piθ=2kπ 对应于数字信号的最低频（直流）；
  • θ=(2k+1)π\theta = (2k+1)\piθ=(2k+1)π 时，序列为 ejπn=(−1)ne^{j\pi n} = (-1)^nejπn=(−1)n，对应信号交替变化最快的最高频。

因此，数字滤波器分类为：

  • 低通：让 θ=2kπ\theta = 2k\piθ=2kπ 附近的低频成分通过，阻断高频。
  • 高通：让 θ=(2k+1)π\theta = (2k+1)\piθ=(2k+1)π 附近的高频成分通过，阻断低频。
  • 带通：阻断低频和高频，仅保留中间的特定频段。
  • 带阻：通过低频和高频，滤去中间的特定频段。

数字滤波器主要分为两类：

  1. 无限冲激响应 (IIR) 滤波器：
    采用递归结构（包含反馈项，输出不仅与当前及过去的输入有关，还与过去的输出有关）。
    其差分方程为后向递归形式：

    y(n)=∑i=0Mbie(n−i)−∑k=1Naky(n−k)y(n) = \sum_{i=0}^{M} b_i e(n-i) - \sum_{k=1}^{N} a_k y(n-k) y(n)=i=0∑M​bi​e(n−i)−k=1∑N​ak​y(n−k)

    系统函数为：

    H(z)=∑i=0Mbiz−i1+∑k=1Nakz−kH(z) = \frac{\sum_{i=0}^{M} b_i z^{-i}}{1 + \sum_{k=1}^{N} a_k z^{-k}} H(z)=1+∑k=1N​ak​z−k∑i=0M​bi​z−i​

  2. 有限冲激响应 (FIR) 滤波器：
    采用非递归结构（仅与当前及过去的输入有关，系统不含反馈环路）。
    系统函数只在原点 z=0z = 0z=0 处有极点：

    H(z)=∑i=0Mbiz−iH(z) = \sum_{i=0}^{M} b_i z^{-i} H(z)=i=0∑M​bi​z−i

    时域单位样值响应 h(n)h(n)h(n) 是有限长的。FIR 滤波器本质是对理想低通滤波器（其 ha(t)h_a(t)ha​(t) 是无限长的 SaSaSa 函数）进行截断，即用窗函数法（如矩形窗、汉宁窗）乘上无限长脉冲，并移动时轴保证因果性。

5. IIR 滤波器设计方法 (s 域到 z 域映射)

利用模拟原型滤波器设计 IIR 数字滤波器，即寻找复频域从 s 域到 z 域的转换关系。

5.1 冲激响应不变法

将模拟滤波器的冲激响应 ha(t)h_a(t)ha​(t) 按等间隔抽样作为数字滤波器的样值响应：

h(n)=ha(nTs)h(n) = h_a(n T_s) h(n)=ha​(nTs​)

若将模拟滤波器部分分式展开：Ha(s)=∑i=1MAis−piH_a(s) = \sum_{i=1}^{M} \frac{A_i}{s - p_i}Ha​(s)=∑i=1M​s−pi​Ai​​，则对应的 Z 域系统函数为：

H(z)=∑i=1MAi1−epiTsz−1H(z) = \sum_{i=1}^{M} \frac{A_i}{1 - e^{p_i T_s} z^{-1}} H(z)=i=1∑M​1−epi​Ts​z−1Ai​​

  • 本质：它是将 s 平面的极点 s=pis = p_is=pi​ 直接映射为 z 平面的极点 z=epiTsz = e^{p_i T_s}z=epi​Ts​。
  • 缺点：S 平面到 Z 平面是多值映射，这会导致频域在以 ωs\omega_sωs​ 为周期的延拓上产生频率混叠。对于高通、带阻等滤波器，由于高频成分丰富，此方法无法使用。

5.2 双线性变换法

双线性变换是通过一个单值映射关系，将整个左半 s 平面单值地保角映射到 z 平面的单位圆内部，彻底解决了频率混叠的问题：
