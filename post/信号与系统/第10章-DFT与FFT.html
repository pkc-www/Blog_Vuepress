第10章 离散傅里叶变换与快速傅里叶变换

Avalanche2026/3/29大约 6 分钟信号与系统信号处理课程笔记

1. 离散傅里叶变换 (DFT) 的概念

计算机中表示并处理信号有两个基本要求：无论是在时域还是频域，信号都必须是离散且有限长的。

离散周期信号的级数展开 (DFS) 能够满足离散的要求，但它是无限长的周期信号。我们将有限长序列（长度为 NNN）作为周期信号的单周期（主值区间）来处理，从而引出离散傅里叶变换 (DFT)：

  • 正变换 (DFT)：

    Xd(k)=DFT⁡[xd(n)]=∑n=0N−1xd(n)WNkn,0≤k≤N−1X_d(k) = \operatorname{DFT}[x_d(n)] = \sum_{n=0}^{N-1} x_d(n) W_N^{kn} \quad , \quad 0 \le k \le N-1 Xd​(k)=DFT[xd​(n)]=n=0∑N−1​xd​(n)WNkn​,0≤k≤N−1

  • 逆变换 (IDFT)：

    xd(n)=IDFT⁡[Xd(k)]=1N∑k=0N−1Xd(k)WN−kn,0≤n≤N−1x_d(n) = \operatorname{IDFT}[X_d(k)] = \frac{1}{N} \sum_{k=0}^{N-1} X_d(k) W_N^{-kn} \quad , \quad 0 \le n \le N-1 xd​(n)=IDFT[Xd​(k)]=N1​k=0∑N−1​Xd​(k)WN−kn​,0≤n≤N−1

其中 WN=e−j2πNW_N = e^{-j\frac{2\pi}{N}}WN​=e−jN2π​ 称为旋转因子。

2. DFT 的物理本质

DFT 算法在物理上也就是离散傅里叶级数 (DFS)。我们可以从两个视角来看待它：

  1. 时域周期信号视角：如果认为 xd(n)x_d(n)xd​(n) 是对一个周期信号 xp(n)x_p(n)xp​(n) 的抽样，则有：

    DFT⁡[xd(n)]=DFS⁡[xp(n)](0≤k≤N−1)\operatorname{DFT}[x_d(n)] = \operatorname{DFS}[x_p(n)] \quad (0 \le k \le N-1) DFT[xd​(n)]=DFS[xp​(n)](0≤k≤N−1)

    这说明 DFT 的值是 DFS 在一个周期内（0∼N−10 \sim N-10∼N−1）的谱线值。
  2. 时域非周期信号视角：如果认为 xd(n)x_d(n)xd​(n) 是对一个非周期信号的抽样，则有：

    DFT⁡[xd(n)]=DTFT⁡[xd(n)]∣θ=k2πN(0≤k≤N−1)\operatorname{DFT}[x_d(n)] = \operatorname{DTFT}[x_d(n)]\Big|_{\theta = k\frac{2\pi}{N}} \quad (0 \le k \le N-1) DFT[xd​(n)]=DTFT[xd​(n)]​θ=kN2π​​(0≤k≤N−1)

    这说明 DFT 的值是在频域上对连续的 DTFT 谱进行等间隔抽样，并取一个周期内的值。

3. DFT 的性质

3.1 线性性质

DFT⁡[axd1(n)+bxd2(n)]=aXd1(k)+bXd2(k)\operatorname{DFT}[a x_{d1}(n) + b x_{d2}(n)] = a X_{d1}(k) + b X_{d2}(k) DFT[axd1​(n)+bxd2​(n)]=aXd1​(k)+bXd2​(k)

3.2 圆周时移性质

在圆周时移下，序列进行首尾衔接的循环移位，保持序列长度不变。

  • 运算步骤：
    1. 周期延拓：将 xd(n)x_d(n)xd​(n) 延拓为周期序列 xp(n)=xd((n))Nx_p(n) = x_d((n))_Nxp​(n)=xd​((n))N​；
    2. 线性时移：在时域进行平移得到 xp(n±m)=xd((n±m))Nx_p(n \pm m) = x_d((n \pm m))_Nxp​(n±m)=xd​((n±m))N​；
    3. 截取主值：用窗口函数 RN(n)R_N(n)RN​(n) 截取 0≤n≤N−10 \le n \le N-10≤n≤N−1 区间，表示为 xd((n±m))NRN(n)x_d((n \pm m))_N R_N(n)xd​((n±m))N​RN​(n)。
  • 时移特性：

    DFT⁡[xd((n−m))NRN(n)]=WNkmXd(k)\operatorname{DFT}[x_d((n - m))_N R_N(n)] = W_N^{km} X_d(k) DFT[xd​((n−m))N​RN​(n)]=WNkm​Xd​(k)

3.3 圆周频移性质

IDFT⁡[Xd((k−l))NRN(k)]=WN−lnxd(n)\operatorname{IDFT}[X_d((k - l))_N R_N(k)] = W_N^{-ln} x_d(n) IDFT[Xd​((k−l))N​RN​(k)]=WN−ln​xd​(n)

3.4 时域圆周卷积性质

两个等长序列 x1(n)x_1(n)x1​(n) 与 x2(n)x_2(n)x2​(n)（长度为 NNN）的圆周卷积定义为：

y(n)=x1(n) N◯ x2(n)=∑m=0N−1x1(m)x2((n−m))NRN(n),0≤n≤N−1y(n) = x_1(n) \text{ \textcircled{N} } x_2(n) = \sum_{m=0}^{N-1} x_1(m) x_2((n - m))_N R_N(n) \quad , \quad 0 \le n \le N-1 y(n)=x1​(n) N◯ x2​(n)=m=0∑N−1​x1​(m)x2​((n−m))N​RN​(n),0≤n≤N−1

其计算过程包括：反褶、周期延拓、圆周平移、相乘求和。

  • 例：已知 x1(n)={1,2,3,4}x_1(n) = \{1, 2, 3, 4\}x1​(n)={1,2,3,4}，x2(n)={1,2,2,1}x_2(n) = \{1, 2, 2, 1\}x2​(n)={1,2,2,1}，求它们的 4 点圆周卷积。

    • n=0n=0n=0：x2((−m))4={1,1,2,2}x_2((-m))_4 = \{1, 1, 2, 2\}x2​((−m))4​={1,1,2,2}。内积：1⋅1+2⋅1+3⋅2+4⋅2=171\cdot 1 + 2\cdot 1 + 3\cdot 2 + 4\cdot 2 = 171⋅1+2⋅1+3⋅2+4⋅2=17
    • n=1n=1n=1：x2((1−m))4={2,1,1,2}x_2((1-m))_4 = \{2, 1, 1, 2\}x2​((1−m))4​={2,1,1,2}。内积：1⋅2+2⋅1+3⋅1+4⋅2=151\cdot 2 + 2\cdot 1 + 3\cdot 1 + 4\cdot 2 = 151⋅2+2⋅1+3⋅1+4⋅2=15
    • n=2n=2n=2：x2((2−m))4={2,2,1,1}x_2((2-m))_4 = \{2, 2, 1, 1\}x2​((2−m))4​={2,2,1,1}。内积：1⋅2+2⋅2+3⋅1+4⋅1=131\cdot 2 + 2\cdot 2 + 3\cdot 1 + 4\cdot 1 = 131⋅2+2⋅2+3⋅1+4⋅1=13
    • n=3n=3n=3：x2((3−m))4={1,2,2,1}x_2((3-m))_4 = \{1, 2, 2, 1\}x2​((3−m))4​={1,2,2,1}。内积：1⋅1+2⋅2+3⋅2+4⋅1=151\cdot 1 + 2\cdot 2 + 3\cdot 2 + 4\cdot 1 = 151⋅1+2⋅2+3⋅2+4⋅1=15
      故圆周卷积结果为 y(n)={17,15,13,15}y(n) = \{17, 15, 13, 15\}y(n)={17,15,13,15}。

  • 圆周卷积定理：
    时域圆周卷积等效于频域乘积。

    DFT⁡[x1(n) N◯ x2(n)]=X1(k)⋅X2(k)\operatorname{DFT}[x_1(n) \text{ \textcircled{N} } x_2(n)] = X_1(k) \cdot X_2(k) DFT[x1​(n) N◯ x2​(n)]=X1​(k)⋅X2​(k)

    这意味着我们可以通过快速傅里叶变换 (FFT) 和逆变换来高效计算圆周卷积：

    x1(n) N◯ x2(n)=IDFT⁡[X1(k)⋅X2(k)]x_1(n) \text{ \textcircled{N} } x_2(n) = \operatorname{IDFT}\left[ X_1(k) \cdot X_2(k) \right] x1​(n) N◯ x2​(n)=IDFT[X1​(k)⋅X2​(k)]

3.5 DFT 的奇偶对称性

对于实序列 xd(n)x_d(n)xd​(n)，其 DFT Xd(k)X_d(k)Xd​(k) 的实部和虚部具有对称性：

Xd(k)=Xdr(k)+jXdi(k)X_d(k) = X_{dr}(k) + j X_{di}(k) Xd​(k)=Xdr​(k)+jXdi​(k)

Xdr(k)=∑n=0N−1xd(n)cos⁡(2πNkn)(实部，关于 N/2 偶对称)X_{dr}(k) = \sum_{n=0}^{N-1} x_d(n) \cos\left( \frac{2\pi}{N}kn \right) \quad (\text{实部，关于 } N/2 \text{ 偶对称}) Xdr​(k)=n=0∑N−1​xd​(n)cos(N2π​kn)(实部，关于 N/2 偶对称)

Xdi(k)=−∑n=0N−1xd(n)sin⁡(2πNkn)(虚部，关于 N/2 奇对称)X_{di}(k) = -\sum_{n=0}^{N-1} x_d(n) \sin\left( \frac{2\pi}{N}kn \right) \quad (\text{虚部，关于 } N/2 \text{ 奇对称}) Xdi​(k)=−n=0∑N−1​xd​(n)sin(N2π​kn)(虚部，关于 N/2 奇对称)

由此可得共轭对称性：

Xd(N−k)=Xd∗(k)  ⟹  ∣Xd(N−k)∣=∣Xd(k)∣,φ(N−k)=−φ(k)X_d(N - k) = X_d^*(k) \implies |X_d(N-k)| = |X_d(k)| \quad , \quad \varphi(N-k) = -\varphi(k) Xd​(N−k)=Xd∗​(k)⟹∣Xd​(N−k)∣=∣Xd​(k)∣,φ(N−k)=−φ(k)

  • 若 xd(n)x_d(n)xd​(n) 为实偶序列   ⟹  \implies⟹ Xd(k)X_d(k)Xd​(k) 为实偶；
  • 若 xd(n)x_d(n)xd​(n) 为实奇序列   ⟹  \implies⟹ Xd(k)X_d(k)Xd​(k) 为虚奇。

3.6 能量守恒 (Parseval 定理)

∑n=0N−1∣xd(n)∣2=1N∑k=0N−1∣Xd(k)∣2\sum_{n=0}^{N-1} |x_d(n)|^2 = \frac{1}{N} \sum_{k=0}^{N-1} |X_d(k)|^2 n=0∑N−1​∣xd​(n)∣2=N1​k=0∑N−1​∣Xd​(k)∣2

4. 快速傅里叶变换 (FFT)

DFT 的计算量很大（需要 N2N^2N2 次复数乘法）。FFT 利用旋转因子 WNknW_N^{kn}WNkn​ 的周期性与对称性，消除了重复计算。

  • WNW_NWN​ 的基本特性：
    1. 周期性：WNk(n+N)=WNknW_N^{k(n+N)} = W_N^{kn}WNk(n+N)​=WNkn​，以及 WN(k+N)n=WNknW_N^{(k+N)n} = W_N^{kn}WN(k+N)n​=WNkn​
    2. 对称性：WNkn+N/2=−WNknW_N^{kn + N/2} = -W_N^{kn}WNkn+N/2​=−WNkn​

以时域抽取基-2 FFT (Cooley-Tukey 算法) 为例，设序列长度为 N=2MN = 2^MN=2M，我们将 xd(n)x_d(n)xd​(n) 按索引的奇偶性分为两组：

Xd(k)=∑n=0N−1xd(n)WNkn=∑r=0N/2−1x(2r)WN2rk+∑r=0N/2−1x(2r+1)WN(2r+1)kX_d(k) = \sum_{n=0}^{N-1} x_d(n) W_N^{kn} = \sum_{r=0}^{N/2-1} x(2r) W_N^{2rk} + \sum_{r=0}^{N/2-1} x(2r+1) W_N^{(2r+1)k} Xd​(k)=n=0∑N−1​xd​(n)WNkn​=r=0∑N/2−1​x(2r)WN2rk​+r=0∑N/2−1​x(2r+1)WN(2r+1)k​

由于 WN2rk=WN/2rkW_N^{2rk} = W_{N/2}^{rk}WN2rk​=WN/2rk​，上式化简为：

Xd(k)=Xe(k)+WNkXo(k)(0≤k≤N2−1)X_d(k) = X_e(k) + W_N^k X_o(k) \quad \left( 0 \le k \le \frac{N}{2} - 1 \right) Xd​(k)=Xe​(k)+WNk​Xo​(k)(0≤k≤2N​−1)

Xd(k+N2)=Xe(k)−WNkXo(k)(0≤k≤N2−1)X_d\left(k + \frac{N}{2}\right) = X_e(k) - W_N^k X_o(k) \quad \left( 0 \le k \le \frac{N}{2} - 1 \right) Xd​(k+2N​)=Xe​(k)−WNk​Xo​(k)(0≤k≤2N​−1)

其中 Xe(k)X_e(k)Xe​(k) 和 Xo(k)X_o(k)Xo​(k) 分别为偶数点和奇数点序列的 N/2N/2N/2 点 DFT。

这构成了 FFT 运算的基本蝴蝶单元。通过多级蝴蝶分裂，可以将复杂度从 O(N2)\mathcal{O}(N^2)O(N2) 降低到 O(Nlog⁡2N)\mathcal{O}(N \log_2 N)O(Nlog2​N)。

  • 码位倒置 (Bit Reversal)：
    为了保证就地运算，第一级输入数据必须按照二进制码位翻转的顺序重新排列（如三位二进制中：001 -> 100，即 x(1)x(1)x(1) 换到 x(4)x(4)x(4) 的位置）。

5. 信号的频谱分析

在用 DFT/FFT 对连续信号进行频谱分析时，有以下关键参数：

  • 抽样频率 fsf_sfs​：单位时间内抽样的次数。

    fs=1Ts≥2fmaxf_s = \frac{1}{T_s} \ge 2 f_{\text{max}} fs​=Ts​1​≥2fmax​

    抽样率决定了能够分析的最大频率范围。

  • 频率分辨率 f1f_1f1​（谱线间隔）：

    f1=Δf=fsN=1NTs=1T0f_1 = \Delta f = \frac{f_s}{N} = \frac{1}{N T_s} = \frac{1}{T_0} f1​=Δf=Nfs​​=NTs​1​=T0​1​

    其中 T0=NTsT_0 = N T_sT0​=NTs​ 为总观测时间（记录长度）。这说明提高频率分辨率的唯一途径是增加观测时间 T0T_0T0​。

  • 例：利用 FFT 分析一个连续非周期信号的频谱。要求频率分辨率 f1=100 Hzf_1 = 100\text{ Hz}f1​=100 Hz，信号中最高频率分量 fmax=3 kHzf_{\text{max}} = 3\text{ kHz}fmax​=3 kHz。确定抽样间隔和抽样长度（点数 NNN）。

    • 确定抽样率：
      根据抽样定理，抽样频率必须满足 fs≥2fmax=6 kHzf_s \ge 2 f_{\text{max}} = 6\text{ kHz}fs​≥2fmax​=6 kHz。

      Ts≤16000 s≈166.7 μsT_s \le \frac{1}{6000}\text{ s} \approx 166.7\ \mu\text{s} Ts​≤60001​ s≈166.7 μs

    • 确定记录时间：
      由频率分辨率要求 T0=1f1=1100 s=10 msT_0 = \frac{1}{f_1} = \frac{1}{100}\text{ s} = 10\text{ ms}T0​=f1​1​=1001​ s=10 ms。
    • 计算抽样点数：

      N=T0fs≥10 ms×6 kHz=60 点N = T_0 f_s \ge 10\text{ ms} \times 6\text{ kHz} = 60\text{ 点} N=T0​fs​≥10 ms×6 kHz=60 点

      因为 FFT 算法要求点数必须为 N=2MN = 2^MN=2M，因此我们向上取整选择 N=64N = 64N=64。
      此时对应的实际抽样率和抽样间隔微调为：

      fs=N⋅f1=64×100=6.4 kHz  ⟹  Ts=16.4 kHz=156.25 μsf_s = N \cdot f_1 = 64 \times 100 = 6.4\text{ kHz} \implies T_s = \frac{1}{6.4\text{ kHz}} = 156.25\ \mu\text{s} fs​=N⋅f1​=64×100=6.4 kHz⟹Ts​=6.4 kHz1​=156.25 μs
