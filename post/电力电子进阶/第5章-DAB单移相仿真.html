第5章 DAB 单移相仿真：MATLAB 脚本与 Simulink 搭建

Avalanche2026/10/23大约 4 分钟电力电子进阶DABMATLAB仿真

1. 目标

  1. 用仿真验证第 4 章推出的电流、功率公式
  2. 亲眼看到 ZVS、回流功率、启动直流偏置这些现象
  3. 为以后复现论文（比如最小回流功率调制）准备一个可以改的模型

2. 参数

取一个 SiC 中压 SST 模块的量级：

参数数值
原边电压 V1V_1V1​800 V
匝比 nnn2 : 1
副边额定电压 V2V_2V2​400 V（M=1M = 1M=1）
开关频率 fsf_sfs​50 kHz
串联电感 LLL（折算到原边）40 μH
绕组等效电阻 RsR_sRs​0.05 Ω
输出电容 CCC100 μF
移相角 φ\varphiφ30°
负载 RRR7.2 Ω（让稳态输出正好 400 V）

3. 方法一：MATLAB 脚本（推荐先跑这个）

脚本 dab_sps.m 放在博客仓库的 src/post/电力电子进阶/仿真/ 目录下，只用基础 MATLAB，不需要 Simulink 或任何工具箱，在 GNU Octave 里也能跑。

展开完整代码
%% DAB 单移相 (SPS) 调制仿真 —— 只用基础 MATLAB，不需要 Simulink / Simscape
% 对应博客《第5章 DAB 单移相仿真》
% 运行方法：把本文件放进 MATLAB 当前文件夹，直接点"运行"
% 也可以在 GNU Octave 里运行（结果相同）
%
% 模型：理想开关 + 漏感 L（折算到原边）+ 绕组电阻 Rs + 输出电容 C + 电阻负载 R
%   原边桥输出   vp = sp * V1,        sp = ±1（50% 方波）
%   副边桥输出   vs = ss * vo,        ss = ±1（滞后 phi 的 50% 方波）
%   L di/dt  = vp - n*vs - Rs*i
%   C dvo/dt = n*ss*i - vo/R

clear; clc; close all;

%% 1. 参数（取一个 SiC 中压 SST 模块的量级）
V1  = 800;        % 原边直流电压 [V]
n   = 2;          % 变比 n:1（原边:副边）
V2n = 400;        % 副边额定电压 [V]，此时 M = n*V2/V1 = 1
fs  = 50e3;       % 开关频率 [Hz]
L   = 40e-6;      % 串联电感（含漏感），折算到原边 [H]
Rs  = 0.05;       % 绕组 + 导通等效电阻 [Ohm]，让启动时的直流偏置能衰减
C   = 100e-6;     % 输出电容 [F]
phi_deg = 30;     % 移相角 [度]，正值表示原边超前 -> 功率从原边流向副边

Ts  = 1/fs;
d   = phi_deg/180;                                   % 移相比 d = phi/pi
P_formula = n*V1*V2n*d*(1-d)/(2*fs*L);               % 理论传输功率
R   = V2n^2/P_formula;                               % 让稳态输出正好落在 400 V 的负载
fprintf('移相 %.0f 度, 理论功率 %.2f kW, 对应负载 R = %.3f Ohm\n', ...
        phi_deg, P_formula/1e3, R);

%% 2. 时域仿真（Heun 二阶积分）
dt   = Ts/720;                                     % 720 步/周期：30 度移相正好是整数步
Tend = 10e-3;
N    = round(Tend/dt);
t    = (0:N-1)*dt;
i    = zeros(1,N);  vo = zeros(1,N);
vp   = zeros(1,N);  vs = zeros(1,N);

sq  = @(x) 2*(mod(x,1) < 0.5) - 1;                   % 占空比 50% 的 ±1 方波
for k = 1:N-1
    tm  = t(k) + dt/2;                               % 取步长中点判断开关状态，避免边沿抖动
    sp  = sq(tm/Ts);
    ss  = sq(tm/Ts - d/2);                           % 副边滞后 d*Ts/2
    di1 = (sp*V1 - n*ss*vo(k) - Rs*i(k))/L;
    dv1 = (n*ss*i(k) - vo(k)/R)/C;
    ip  = i(k) + dt*di1;   vop = vo(k) + dt*dv1;     % 预测
    di2 = (sp*V1 - n*ss*vop - Rs*ip)/L;
    dv2 = (n*ss*ip - vop/R)/C;
    i(k+1)  = i(k)  + dt*(di1+di2)/2;                % 校正
    vo(k+1) = vo(k) + dt*(dv1+dv2)/2;
    vp(k) = sp*V1;  vs(k) = n*ss*vo(k);
end
vp(N) = vp(N-1); vs(N) = vs(N-1);

%% 3. 取最后 10 个周期算稳态指标
idx  = t > Tend - 10*Ts;
P_sim = mean(vp(idx).*i(idx));                       % 原边桥输出的平均功率
fprintf('仿真：Vo = %.1f V, 原边功率 %.2f kW (理论 %.2f kW)\n', ...
        mean(vo(idx)), P_sim/1e3, P_formula/1e3);
fprintf('      电感电流峰值 %.1f A, 有效值 %.1f A\n', ...
        max(abs(i(idx))), sqrt(mean(i(idx).^2)));

%% 4. 画图
figure('Name','DAB SPS');
subplot(3,1,1);
plot(t*1e3, vo, 'LineWidth', 1.2); grid on;
ylabel('v_o [V]'); title('输出电压启动过程');

w = t > Tend - 2*Ts;  tw = (t(w) - t(find(w,1)))*1e6;
subplot(3,1,2);
plot(tw, vp(w), tw, vs(w), 'LineWidth', 1.2); grid on;
ylabel('电压 [V]'); legend('v_p', 'n v_s'); title('稳态两个周期');
subplot(3,1,3);
plot(tw, i(w), 'LineWidth', 1.2); grid on;
xlabel('t [\mus]'); ylabel('i_L [A]');

%% 5. 传输功率 vs 移相角（固定 V2 = 400 V，与公式对比）
phis  = 0:5:180;
P_pts = zeros(size(phis));
for m = 1:numel(phis)
    dm = phis(m)/180;
    % 理想无损、V2 恒定时，电感电流是分段线性的，可以直接写出一周期内的端点
    Th = Ts/2;  M = n*V2n/V1;
    i0 = -V1/(4*fs*L)*(1 - M*(1-2*dm));              % t = 0 时刻电流
    i1 =  V1/(4*fs*L)*(M + 2*dm - 1);                % t = d*Th 时刻电流
    % 半周期内 vp = +V1，平均功率 = V1 * 电流在半周期内的平均值（两段梯形面积）
    area   = (i0+i1)/2*dm*Th + (i1+(-i0))/2*(1-dm)*Th;
    P_pts(m) = V1*area/Th;
end
P_curve = n*V1*V2n*(phis/180).*(1-phis/180)/(2*fs*L);
figure('Name','P-phi');
plot(phis, P_curve/1e3, 'LineWidth', 1.5); hold on;
plot(phis, P_pts/1e3, 'o'); grid on;
xlabel('\phi [度]'); ylabel('P [kW]');
legend('公式 nV_1V_2 d(1-d)/(2f_sL)', '分段线性计算');
title('DAB 单移相传输功率');
fprintf('最大功率出现在 90 度: %.2f kW\n', max(P_curve)/1e3);

模型思路： 开关当作理想的 ±1\pm1±1 开关函数，只保留两个状态变量（电感电流 iii、输出电压 vov_ovo​）：

Ldidt=spV1−nssvo−Rsi,Cdvodt=nssi−voRL\frac{di}{dt} = s_p V_1 - n s_s v_o - R_s i, \qquad C\frac{dv_o}{dt} = n s_s i - \frac{v_o}{R} Ldtdi​=sp​V1​−nss​vo​−Rs​i,Cdtdvo​​=nss​i−Rvo​​

其中 sp,ss∈{+1,−1}s_p, s_s \in \{+1, -1\}sp​,ss​∈{+1,−1} 分别是原边、副边桥的开关函数，副边滞后 dTs/2dT_s/2dTs​/2。用 Heun（改进欧拉）法积分，步长 Ts/720T_s/720Ts​/720。

运行结果（已在 Octave 8.4 中验证）：

移相 30 度, 理论功率 22.22 kW, 对应负载 R = 7.200 Ohm
仿真：Vo = 400.0 V, 原边功率 22.20 kW (理论 22.22 kW)
      电感电流峰值 33.5 A, 有效值 31.5 A
最大功率出现在 90 度: 40.00 kW

功率误差 0.1%，来自 RsR_sRs​ 上的损耗；峰值 33.5 A 和第 4 章手算的 i1=33.3 Ai_1 = 33.3\,\text{A}i1​=33.3A 吻合。

3.1 启动过程

看到了什么：

  • 输出电压约 3 ms 进入稳态
  • 启动瞬间 vo≈0v_o \approx 0vo​≈0，电感两端几乎是整个 V1V_1V1​，电流冲到 200 A，是稳态的 6 倍
  • 电流包络上下不对称，说明里面有直流分量。它只能靠 RsR_sRs​ 以时间常数 L/Rs=0.8 msL/R_s = 0.8\,\text{ms}L/Rs​=0.8ms 慢慢衰减。真实变压器里，这个直流分量会造成偏磁甚至饱和

工程上的对策： 软启动（移相角从 0 慢慢加大）、启动时第一个半周期用半宽脉冲、串隔直电容。这些都是以后读论文会遇到的"DAB 暂态直流偏置抑制"问题。

4. 方法二：在 Simulink 中搭建（用真实开关器件）

脚本模型的开关是理想的，看不到死区和 ZVS 换流细节。下面用 Simscape Electrical → Specialized Power Systems 搭一个器件级模型。

说明：这部分步骤我没有在 MATLAB 里实际搭建验证，模块名称以 R2023 前后版本为准，不同版本可能略有差别。如果卡住，把报错发给我。

步骤：

  1. 新建模型，放入 powergui，仿真类型选 Discrete，采样时间 Ts_sim = 1e-8（开关周期 20 μs 的 1/2000）
  2. 原边： DC Voltage Source（800 V）→ Universal Bridge（2 桥臂，器件选 MOSFET/Diodes，即全桥）
  3. 电感与变压器： Series RLC Branch（只保留 L = 40 μH，R = 0.05 Ω）→ Linear Transformer（两绕组，额定电压比 2:1，频率填 50e3；励磁电阻和电感设大，近似理想）
  4. 副边： 另一个 Universal Bridge（全桥）→ Capacitor 100 μF 并联 Resistor 7.2 Ω
  5. 驱动信号： 4 个 Pulse Generator
    • 原边 A 臂：周期 1/50e3，占空比 50%，相位延时 0；B 臂延时半个周期
    • 副边两个桥臂同理，但整体再延时 (30/360)/50e3 秒
    • 用 NOT 产生下管信号，各桥的 4 路信号用 Mux 送入 Universal Bridge 的 g 端
    • 进阶：在上下管之间加 200 ns 死区（可用 Transport Delay + 逻辑与实现）
  6. 测量： Voltage Measurement 测两桥输出电压，Current Measurement 测电感电流，接 Scope
  7. 仿真 10 ms，和第 3 节的脚本结果对比：稳态 vov_ovo​ 应接近 400 V，电感电流峰值约 33 A

5. 练习（建议做完再进入第 2 步）

  1. 验证公式： 把 φ\varphiφ 改成 10°、45°、60°，记录仿真功率并和公式比较
  2. 电压不匹配： 把负载改到让 V2=300 VV_2 = 300\,\text{V}V2​=300V（M=0.75M=0.75M=0.75），看 φ=15°\varphi=15°φ=15° 时 i1i_1i1​ 是否变负（副边丢失 ZVS），对照 ZVS 区域图
  3. 回流功率： 在脚本里计算 ∫p<0p dt\int_{p<0} p\,dt∫p<0​pdt，验证 PbfP_{bf}Pbf​ 公式；再观察 φ\varphiφ 越小，回流占比越大
  4. 软启动： 让 φ\varphiφ 在前 2 ms 从 0 线性增加到 30°，对比启动冲击电流和直流偏置
  5. 进阶（Simulink）： 加死区，观察开关管电压在开通前是否已经降到 0（ZVS），减小负载看 ZVS 何时丢失
