第4章 双有源桥（DAB）：固态变压器的核心隔离级

Avalanche2026/10/23大约 7 分钟电力电子进阶电力电子DAB固态变压器

1. 结构：两个全桥夹一个电感

把 PSFB 副边的二极管整流桥换成可控全桥，就得到双有源桥（Dual Active Bridge, DAB）：

  • 原边全桥 S1～S4，直流电压 V1V_1V1​
  • 高频变压器，匝比 n:1n:1n:1
  • 串联电感 LLL（漏感 + 外加电感，折算到原边）
  • 副边全桥 Q1～Q4，直流电压 V2V_2V2​

它最早由 De Doncker 等人在 1991 年提出，用于大功率、高功率密度场合。

原副边都是 MOSFET 全桥，LLL 是漏感加外加电感（折算到原边）。和 PSFB 对比，唯一的结构差别是副边二极管 D1～D4 换成了可控开关 Q1～Q4，这让功率可以双向流动。

定义电压增益（副边电压折算到原边与原边电压之比）：

M=nV2V1M = \frac{nV_2}{V_1} M=V1​nV2​​

M=1M=1M=1 叫电压匹配，这时 DAB 性能最好。

2. 单移相调制（SPS, Single Phase Shift）

最简单的控制：

  1. 两个全桥都输出 50% 占空比的 ±\pm± 方波：vp=±V1v_p = \pm V_1vp​=±V1​，vs′=±nV2v_s' = \pm nV_2vs′​=±nV2​
  2. 两个方波之间错开一个移相角 φ\varphiφ（弧度），定义移相比 d=φ/π∈[−1,1]d = \varphi/\pi \in [-1, 1]d=φ/π∈[−1,1]

电感就是"功率阀门"： 两端电压差决定电流斜率，电流再决定功率。和电力系统里两个电压源经电抗传输功率 P=V1V2Xsin⁡δP = \frac{V_1V_2}{X}\sin\deltaP=XV1​V2​​sinδ 是同一个道理（你在电力系统分析里学过）。

4. 传输功率

  1. 天然双向：φ>0\varphi>0φ>0 功率从原边到副边，φ<0\varphi<0φ<0 反过来，不用改电路，只改相位。这正是储能、电动车 V2G、直流电网需要的。

  4. 电感 LLL 的选取：LLL 越小，同样功率需要的移相越小（软开关范围变化），但功率对 φ\varphiφ 越敏感；LLL 由最大功率和预留的控制裕度决定。

5. 软开关（ZVS）条件

沿用第 3 章的思路：开关管关断瞬间，电流方向要能把即将开通那个管子的结电容放完电。

  • 原边 ZVS：原边在 t=0t=0t=0 换流，需要 i0≤0i_0 \le 0i0​≤0

1−M(1−2d)≥0⟺M≤11−2d1 - M(1-2d) \ge 0 \quad\Longleftrightarrow\quad M \le \frac{1}{1-2d} 1−M(1−2d)≥0⟺M≤1−2d1​

  • 副边 ZVS：副边在 t=dTht=dT_ht=dTh​ 换流，需要 i1≥0i_1 \ge 0i1​≥0

M+2d−1≥0⟺M≥1−2dM + 2d - 1 \ge 0 \quad\Longleftrightarrow\quad M \ge 1 - 2d M+2d−1≥0⟺M≥1−2d

读图：

  • M=1M = 1M=1 时，任意 d>0d>0d>0 两侧都能 ZVS（理想情况）
  • MMM 偏离 1 越远，轻载（小 φ\varphiφ）时越容易丢失 ZVS
  • 实际还要考虑结电容能量 CossV2C_{oss}V^2Coss​V2：电流不仅要方向对，还要足够大，所以真实 ZVS 区域比图上更小

工程意义： SST/直流变压器的输入、输出电压往往会波动（电网电压、电池电压），M≠1M \ne 1M=1 是常态，宽电压范围下保持高效率，是 DAB 研究的核心难题之一。

6. 回流功率与电流应力

在 0<t<tz0 < t < t_z0<t<tz​ 这一小段，vp>0v_p > 0vp​>0 而 i<0i < 0i<0，瞬时功率为负，能量从电感倒流回原边电源，叫回流功率（backflow power）：

tz=∣i0∣ LV1+V2′,Pbf=fs V1 L i02V1+V2′t_z = \frac{|i_0|\,L}{V_1+V_2'}, \qquad P_{bf} = \frac{f_s\,V_1\,L\,i_0^2}{V_1+V_2'} tz​=V1​+V2′​∣i0​∣L​,Pbf​=V1​+V2′​fs​V1​Li02​​

上例 Pbf≈1.1 kWP_{bf} \approx 1.1\,\text{kW}Pbf​≈1.1kW，约占传输功率 22.2 kW 的 5%。

回流功率本身不是"损耗"，但它让电流有效值和峰值变大，导通损耗、器件和变压器的电流应力都跟着变大。

有意思的矛盾：

  • 原边 ZVS 需要 i0≤0i_0 \le 0i0​≤0，也就是需要一点回流
  • 回流太多又增加损耗

所以"最小回流功率"与"保持 ZVS"之间的折中，是 DAB 调制策略研究的一条主线。赵彪老师 2023 年的论文 An IGCT-Series-Based DC Transformer With Quasi-Zero Switching Loss Modulation by Minimum Backflow Power Injection 就是这个思路在 IGCT 大功率直流变压器上的应用：只注入"刚好够用"的回流功率来实现软开关。

7. 更多自由度：EPS、DPS、TPS

SPS 只有一个控制量 φ\varphiφ，M≠1M\ne1M=1 时性能差。改进办法是让全桥输出三电平波形（类似 PSFB），在桥内也引入移相：

调制方式控制自由度说明
SPS 单移相1（桥间移相 φ\varphiφ）最简单，M≠1M\ne1M=1 时回流大、ZVS 范围窄
EPS 扩展移相2（φ\varphiφ + 一侧桥内移相）赵彪等 2012 年在 IEEE TPEL 上系统提出，减小回流功率
DPS 双重移相2（φ\varphiφ + 两侧相同的桥内移相）降低电流应力，改善动态
TPS 三重移相3（全部独立）统一框架，可以做电流有效值/损耗最优化

这一块是第 2 步"论文精读"的重点，届时会结合赵老师的综述逐篇读。

8. DAB 在固态变压器（SST）中的位置

典型三级式 SST（以 10 kV 交流电网 → 800 V 直流为例）：

中压 AC/DC⏟级联 H 桥 / MMC 整流  →  隔离 DC/DC⏟DAB 或 CLLC 模块  →  低压 DC/AC 或 DC/DC⏟可选\underbrace{\text{中压 AC/DC}}_{\text{级联 H 桥 / MMC 整流}} \;\to\; \underbrace{\text{隔离 DC/DC}}_{\text{DAB 或 CLLC 模块}} \;\to\; \underbrace{\text{低压 DC/AC 或 DC/DC}}_{\text{可选}} 级联 H 桥 / MMC 整流中压 AC/DC​​→DAB 或 CLLC 模块隔离 DC/DC​​→可选低压 DC/AC 或 DC/DC​​

  • 单个功率器件耐压有限（常用 SiC MOSFET 1.2～3.3 kV），10 kV 级需要把很多个 DAB 模块输入串联、输出并联（ISOP），模块间均压均流是关键问题

  • AI 数据中心的新趋势是 800 V 高压直流配电：SST 直接从中压电网变成 800 VDC 送到机柜，省掉工频变压器和多级 AC/DC，效率和占地都更优
  • 更高电压、更大功率时（如直流电网、海上风电），会用 IGCT、MMC 型的直流变压器，这正是赵彪老师组的研究范围
