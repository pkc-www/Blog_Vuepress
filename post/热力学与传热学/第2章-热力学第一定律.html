第2章 热力学第一定律

Avalanche2026/11/1大约 18 分钟热力学与传热学工程热力学热力学第一定律能量方程课程笔记

2.1 热力学第一定律的本质与能量收支通式

  1. 物理本质：自然界一切物质都具有能量，能量既不能凭空产生，也不能凭空消灭，只能从一种形式转化为另一种形式，或从一个系统传递给另一个系统，在转化和传递过程中能量的总量保持恒定（即能量守恒与转换定律在热现象领域的表达）。
  2. 第一类永动机（Perpetual Motion Machine of the First Kind）：不消耗任何能量却能持续对外做功的机器。热力学第一定律直接宣判：第一类永动机绝对不可能实现。
  3. 热功当量：焦耳（Joule）实验证明热与功具有严格的定量转换关系（1 cal=4.1868 J1\text{ cal} = 4.1868\text{ J}1 cal=4.1868 J）。
  4. 任何热力系统的通用能量平衡收支式：

    进入系统的总能量 Ein−离开系统的总能量 Eout=系统储存能的增量 ΔEsys\boxed{\text{进入系统的总能量 } E_{\text{in}} - \text{离开系统的总能量 } E_{\text{out}} = \text{系统储存能的增量 } \Delta E_{\text{sys}}} 进入系统的总能量 Ein​−离开系统的总能量 Eout​=系统储存能的增量 ΔEsys​​

2.2 热力系统的储存能与热力学能（内能 UUU）

1. 热力学能（Internal Energy，UUU）的引出與物理意义

对任意经历循环的闭口系统，实验定律给出循环热功相等：

∮δQ=∮δW⟹∮(δQ−δW)=0\oint \delta Q = \oint \delta W \quad \Longrightarrow \quad \oint (\delta Q - \delta W) = 0 ∮δQ=∮δW⟹∮(δQ−δW)=0

由第一章的状态参数环积分判据可知，组合量 (δQ−δW)(\delta Q - \delta W)(δQ−δW) 必然是某个状态参数的全微分！当忽略系统整体的宏观动能和位能变化时，定义该状态参数为系统的热力学能（简称内能，UUU，比内能 u=U/mu = U/mu=U/m）：

dU=δQ−δW\mathrm{d}U = \delta Q - \delta W dU=δQ−δW

  • 内能 UUU 的微观构成：
    1. 分子热运动内动能 UkU_kUk​（平动、转动、振动动能）：仅取决于分子热运动剧烈程度，即仅是温度 TTT 的函数；
    2. 分子间相互作用内位能 UpU_pUp​：取决于分子间距，即是比体积 vvv（及温度 TTT）的函数；
    3. 化学能与原子核能（在无化学反应与核反应的简单可压缩系统中保持常数）。
  • 一般工质内能的函数形式：对于简单可压缩系统，u=f(T,v)u = f(T, v)u=f(T,v)（选两个独立状态参数即可唯一确定）。

重要

焦耳自由膨胀实验结论：理想气体的内能仅是温度的函数！ 焦耳（1843）将装有高压空气的容器与真空容器放入绝热水槽中，打开阀门让气体向真空自由膨胀：

  • 取整个双联容器为闭口绝热刚性系统：Q=0,W=0  ⟹  ΔU=Q−W=0Q = 0, W = 0 \implies \Delta U = Q - W = 0Q=0,W=0⟹ΔU=Q−W=0；
  • 实验测得膨胀前后水温几乎不变（ΔT=0\Delta T = 0ΔT=0），尽管比体积 vvv 大幅增大，但内能 UUU 不随 vvv 改变！
  • 核心结论：理想气体忽略分子间作用力（内位能 Up=0U_p = 0Up​=0），因此理想气体的热力学能 uuu 仅仅是温度 TTT 的单值函数：

    u=f(T)（仅限理想气体！）u = f(T) \quad \text{（仅限理想气体！）} u=f(T)（仅限理想气体！）

2.4 开口系能量方程：推动功与状态参数“焓（Enthalpy）”

1. 推动功（流动功，Flow Work，w推w_{\text{推}}w推​）

开口系（控制容积 CV）与闭口系的最大区别在于：有质量 δm\delta mδm 跨越边界进出系统。当微元流体团 δm\delta mδm 在截面压力 ppp 的推动下流入或流出控制容积时，后面的流体必须推着前面的流体移动，从而在进出口截面上传递了机械功——称为推动功（或流动功）：

当单位质量工质跨越开口系边界时，它不仅自身携带着热力学能 uuu，还必然伴随着进出边界的推动功 pvpvpv。由于 uuu 和 pvpvpv 总是成对出现，定义组合状态参数 焓 HHH（比焓 h=H/mh = H/mh=H/m）：

2.5 稳定流动能量方程（SFEE）与四种功的转换关系

1. 稳定流动（Steady Flow）的四大条件

工程上绝大多数连续运行的动力与化工设备（汽轮机、压气机、喷管、换热器、节流阀）均工作在稳定流动状态，满足：

  1. 质量守恒（连续性方程）：流入与流出质量流量相等且不随时间变化：

    m˙1=m˙2=m˙=A1c1v1=A2c2v2=const\dot{m}_1 = \dot{m}_2 = \dot{m} = \frac{A_1 c_1}{v_1} = \frac{A_2 c_2}{v_2} = \text{const} m˙1​=m˙2​=m˙=v1​A1​c1​​=v2​A2​c2​​=const

  2. 进出口状态稳定：进出口截面上工质的状态参数 (p,T,v,h,c,z)(p, T, v, h, c, z)(p,T,v,h,c,z) 不随时间改变；
  3. 热功率与轴功率恒定：Q˙=const,W˙s=const\dot{Q} = \text{const}, \dot{W}_s = \text{const}Q˙​=const,W˙s​=const；
  4. 控制体内储存能不变：dEcvdτ=0\frac{\mathrm{d}E_{\text{cv}}}{\mathrm{d}\tau} = 0dτdEcv​​=0。
