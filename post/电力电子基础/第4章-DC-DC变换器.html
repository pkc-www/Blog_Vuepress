Basic Principle

where D=ton/TsD = t_{on}/T_sD=ton​/Ts​ is the duty ratio.

Two methods to control VoV_oVo​:

  1. Frequency fixed, on-duration adjusted: PWM (pulse-width modulation);
  2. Both frequency and on-duration adjusted.

PWM is the usual choice: with a fixed fsf_sfs​ the harmonics sit at known frequencies, which makes the filter design much easier.

Commutation:

A controllable switch and a diode form one leg. Whichever way the current iAi_AiA​ flows, either a switch or the diode of the same position carries it, so vANv_{AN}vAN​ is set only by the switching state:

  • TA+T_{A+}TA+​ on (or DA+D_{A+}DA+​ conducting): vAN=Vdv_{AN} = V_dvAN​=Vd​
  • TA−T_{A-}TA−​ on (or DA−D_{A-}DA−​ conducting): vAN=0v_{AN} = 0vAN​=0

All the converters below are built from this unit.

1. Buck Regulators

Assumptions:

  1. Steady state: IC=0I_C = 0IC​=0, IL=IoI_L = I_oIL​=Io​, VL=0V_L = 0VL​=0 over a cycle (averages);
  2. Continuous conduction: iLi_LiL​ stays positive and continuous;
  3. Large CCC: VC=constV_C = \text{const}VC​=const.

The inductor current rises by ΔIL\Delta I_LΔIL​ while on and falls by the same amount while off:

{Vd−Vo=LΔILton−Vo=−LΔILtoff\begin{cases} V_d - V_o = L\dfrac{\Delta I_L}{t_{on}} \\[2mm] -V_o = -L\dfrac{\Delta I_L}{t_{off}} \end{cases} ⎩⎨⎧​Vd​−Vo​=Lton​ΔIL​​−Vo​=−Ltoff​ΔIL​​​

Discontinuous Conduction

At light load iLi_LiL​ falls to zero before the end of the period. Boundary between continuous and discontinuous conduction:

(Vd−Vo)D=VoΔ1  ⇒  VoVd=DD+Δ1(V_d - V_o)D = V_o \Delta_1 \;\Rightarrow\; \boxed{\frac{V_o}{V_d} = \frac{D}{D + \Delta_1}} (Vd​−Vo​)D=Vo​Δ1​⇒Vd​Vo​​=D+Δ1​D​​

In DCM the output voltage depends on the load current, not on DDD alone.

Conclusion of Buck:

  1. Step down (D<1D < 1D<1);
  2. Simple, only one active device;
  3. High efficiency.

The input current is pulsating, so an input filter is usually needed.

2. Boost Regulators

{Vd=LΔILtonVd−Vo=−LΔILtoff\begin{cases} V_d = L\dfrac{\Delta I_L}{t_{on}} \\[2mm] V_d - V_o = -L\dfrac{\Delta I_L}{t_{off}} \end{cases} ⎩⎨⎧​Vd​=Lton​ΔIL​​Vd​−Vo​=−Ltoff​ΔIL​​​

3. Buck-Boost Regulators

Cascade of Buck and Boost:

Merging the two stages and removing the redundant middle capacitor and switch leaves a single inductor that is charged from VdV_dVd​ when on and discharged into the output when off. The output polarity is reversed.

CCM: volt-second balance VdD=Vo(1−D)V_d D = V_o(1 - D)Vd​D=Vo​(1−D):

Vo=VdD1−D\boxed{V_o = \frac{V_d D}{1 - D}} Vo​=1−DVd​D​​

DDD in the numerator comes from the buck stage, 1−D1 - D1−D in the denominator from the boost stage: D<0.5D < 0.5D<0.5 steps down, D>0.5D > 0.5D>0.5 steps up.

Id=IoD1−D\boxed{I_d = \frac{I_o D}{1 - D}} Id​=1−DIo​D​​

ΔIL\Delta I_LΔIL​ is the same as Boost:

ΔIL=VdDfsL\boxed{\Delta I_L = \frac{V_d D}{f_s L}} ΔIL​=fs​LVd​D​​

ΔVo\Delta V_oΔVo​ is the same as Boost:

ΔVo=IoDfsC\boxed{\Delta V_o = \frac{I_o D}{f_s C}} ΔVo​=fs​CIo​D​​

DCM:

Boundary: ILB=12ΔIL,IoB=ILB(1−D),ΔIL=VdDfsL\text{Boundary: } I_{LB} = \frac{1}{2}\Delta I_L, \qquad I_{oB} = I_{LB}(1 - D), \qquad \Delta I_L = \frac{V_d D}{f_s L} Boundary: ILB​=21​ΔIL​,IoB​=ILB​(1−D),ΔIL​=fs​LVd​D​

Δ1=2fsLVdD⋅Io,VoVd=DΔ1\Delta_1 = \frac{2 f_s L}{V_d D} \cdot I_o, \qquad \frac{V_o}{V_d} = \frac{D}{\Delta_1} Δ1​=Vd​D2fs​L​⋅Io​,Vd​Vo​​=Δ1​D​

(from the volt-second balance VdD=VoΔ1V_d D = V_o \Delta_1Vd​D=Vo​Δ1​).

4. Ćuk Regulators

Cascade of Boost and Buck:

Caution! After the middle stage is replaced by the coupling capacitor C1C_1C1​, the output capacitor and the load voltage are reversed.

Energy is transferred from the input to the output through C1C_1C1​. In steady state with large capacitors:

  • Switch off: iL1i_{L1}iL1​ charges C1C_1C1​ through DDD, vL1=Vd−VC1v_{L1} = V_d - V_{C1}vL1​=Vd​−VC1​; L2L_2L2​ freewheels through DDD, vL2=−Vov_{L2} = -V_ovL2​=−Vo​.
  • Switch on: C1C_1C1​ discharges into L2L_2L2​ and the load through TTT, vL2=VC1−Vov_{L2} = V_{C1} - V_ovL2​=VC1​−Vo​; vL1=Vdv_{L1} = V_dvL1​=Vd​.

Volt-second balance on L1L_1L1​ and L2L_2L2​:

VdD+(Vd−VC1)(1−D)=0  ⇒  VC1=Vd1−DV_d D + (V_d - V_{C1})(1 - D) = 0 \;\Rightarrow\; V_{C1} = \frac{V_d}{1 - D} Vd​D+(Vd​−VC1​)(1−D)=0⇒VC1​=1−DVd​​

(VC1−Vo)D−Vo(1−D)=0  ⇒  Vo=D VC1(V_{C1} - V_o) D - V_o (1 - D) = 0 \;\Rightarrow\; V_o = D\,V_{C1} (VC1​−Vo​)D−Vo​(1−D)=0⇒Vo​=DVC1​

VoVd=D1−D\boxed{\frac{V_o}{V_d} = \frac{D}{1 - D}} Vd​Vo​​=1−DD​​

This is the same ratio as the buck-boost (also inverted). Inductors on both sides make both the input and the output current continuous with small ripple. The drawback is that C1C_1C1​ carries a large ripple current.

5. Full-bridge Regulator

Four-quadrant operation is possible, in order to get vo ±v_o\ \pmvo​ ± and io ±i_o\ \pmio​ ±.

Basic principles:

  • (TA+,TA−)=(1,0)(T_{A+}, T_{A-}) = (1, 0)(TA+​,TA−​)=(1,0) or (0,1)(0, 1)(0,1): vAN=Vdv_{AN} = V_dvAN​=Vd​ or 000. The same applies to TB+T_{B+}TB+​, TB−T_{B-}TB−​: vBN=Vdv_{BN} = V_dvBN​=Vd​ or 000. Output vo=vAN−vBNv_o = v_{AN} - v_{BN}vo​=vAN​−vBN​.

PWM with Bipolar Voltage Switching

vtriv_{tri}vtri​ is compared with vcontrolv_{control}vcontrol​:

  • vcontrol>vtriv_{control} > v_{tri}vcontrol​>vtri​: TA+T_{A+}TA+​, TB−T_{B-}TB−​ on, vAN=+Vdv_{AN} = +V_dvAN​=+Vd​, vBN=0v_{BN} = 0vBN​=0, vo=+Vdv_o = +V_dvo​=+Vd​;
  • vcontrol<vtriv_{control} < v_{tri}vcontrol​<vtri​: TA−T_{A-}TA−​, TB+T_{B+}TB+​ on, vAN=0v_{AN} = 0vAN​=0, vBN=+Vdv_{BN} = +V_dvBN​=+Vd​, vo=−Vdv_o = -V_dvo​=−Vd​.

The output jumps between +Vd+V_d+Vd​ and −Vd-V_d−Vd​, hence "bipolar". With the duty ratio D1D_1D1​ of the pair (TA+,TB−)(T_{A+}, T_{B-})(TA+​,TB−​):

D1=12(1+vcontrolV^tri),Vo=(2D1−1)Vd=VdV^tri vcontrolD_1 = \frac{1}{2}\left(1 + \frac{v_{control}}{\hat{V}_{tri}}\right), \qquad V_o = (2D_1 - 1)V_d = \boxed{\frac{V_d}{\hat{V}_{tri}}\, v_{control}} D1​=21​(1+V^tri​vcontrol​​),Vo​=(2D1​−1)Vd​=V^tri​Vd​​vcontrol​​

so the average output voltage is linear in vcontrolv_{control}vcontrol​.

PWM with Unipolar Voltage Switching

The two legs are controlled separately: leg A compares vcontrolv_{control}vcontrol​ with vtriv_{tri}vtri​, and leg B compares −vcontrol-v_{control}−vcontrol​ with vtriv_{tri}vtri​. Now vov_ovo​ switches between +Vd+V_d+Vd​ and 000 (or 000 and −Vd-V_d−Vd​).

  • The average Vo=VdV^tri vcontrolV_o = \dfrac{V_d}{\hat{V}_{tri}}\, v_{control}Vo​=V^tri​Vd​​vcontrol​ is the same as for bipolar switching;
  • The voltage steps are only VdV_dVd​ instead of 2Vd2V_d2Vd​, and the effective switching frequency of vov_ovo​ is doubled, so the output ripple is much smaller.
