## 6. 论文里的常用表达

| 中文意思 | 英文常见写法 |
|---|---|
| 本文提出了…… | This paper proposes / presents ... |
| 与……相比 | Compared with ..., / In contrast to ... |
| 实验结果验证了…… | Experimental results verify / validate ... |
| 在全负载范围内实现 ZVS | achieve ZVS over the full load range |
| 宽电压范围 | wide voltage range |
| 拓扑推导 | topology derivation |
| 调制策略 | modulation strategy / scheme |
| 闭式解 | closed-form solution |
| 不失一般性 | without loss of generality |
| 样机 | prototype |
