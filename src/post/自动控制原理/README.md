自动控制原理（Automatic Control System）课程笔记，按章整理控制系统基础、数学模型、时域分析与根轨迹、频域分析及经典控制器设计，并在关键章节嵌入可交互仿真实验组件。

## 章节目录

- [第1章 控制系统基础](./第1章-控制系统基础.md) — 方框图基本组成、开环/前向/闭环三个核心传递函数，以及由线性常微分方程导出传递函数的条件与本质属性。
- [第2章 系统的数学模型](./第2章-系统的数学模型.md) — 典型带扰动闭环方框图与等效化简、二级 RC 网络化简、信号流图与梅森公式、状态空间相似变换、可控标准型（CCF）与状态图。
- [第3章 控制系统的时域分析](./第3章-控制系统的时域分析.md) — 李雅普诺夫/渐近/BIBO 稳定性辨析、劳斯-赫尔维茨判据、稳态误差与复合控制、灵敏度分析、一二阶瞬态响应与根轨迹法（含交互实验）。
- [第4章 控制系统的频域分析](./第4章-控制系统的频域分析.md) — 频率特性与极坐标图、柯西幅角原理与奈奎斯特稳定判据、原点极点补圆、伯德图绘制与最小相位系统、幅值/相角裕度（含交互实验）。
- [第5章 控制系统设计与校正](./第5章-控制系统设计与校正.md) — 六类控制器结构配置、控制系统设计 8 条基本原则、PID 与相位超前/滞后校正器特性及无源 RC 实现、时域根轨迹与频域伯德图设计步骤。
