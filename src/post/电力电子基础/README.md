电力电子基础课程笔记（英文），从功率器件讲起，依次覆盖二极管整流、晶闸管相控整流和 DC-DC 变换器。进一步的隔离型变换器、DAB 与 SST 见[电力电子进阶](../电力电子进阶/README.md)。

## 章节目录

- [第1章 功率器件 Power Devices](./第1章-功率器件.md) — 理想与实际开关、功率二极管、晶闸管、GTR、功率 MOSFET 与 IGBT。
- [第2章 二极管整流电路 Diode Rectifiers](./第2章-二极管整流电路.md) — 单相与三相桥式整流、谐波分析与功率因数、交流侧电感引起的换相重叠。
- [第3章 晶闸管相控整流 Thyristor AC-DC Converters](./第3章-晶闸管相控整流.md) — 触发延迟角、单相与三相晶闸管桥、逆变运行与熄弧角。
- [第4章 直流-直流变换器 DC-DC Converters](./第4章-DC-DC变换器.md) — Buck、Boost、Buck-Boost、Cuk 的连续/断续导通分析，全桥变换器与 PWM。
