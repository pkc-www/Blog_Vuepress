热力学与传热学基础课程笔记，重点梳理工程热力学与传热学的核心概念、具体分析方法、公式适用条件与典型工程案例。

## 章节目录

- [第0章 绪论](./第0章-绪论.md) — 能源转换链、动力与制冷循环范式、工程热力学与传热学的研究对象与方法论对比。
- [第1章 基本概念](./第1章-基本概念.md) — 热力系统选取与分类、状态参数与全微分判据、状态公理、准平衡与可逆过程、容积功与示功/示热图。
- [第2章 热力学第一定律](./第2章-热力学第一定律.md) — 热力学能与焓、闭口系与开口系能量方程、稳定流动能量方程（SFEE）、四种功的转换关系、五大典型热力设备及充放气系统选取方法。
- [第3章 理想气体的性质与热力过程](./第3章-理想气体的性质与热力过程.md) — 理想气体状态方程、比热容与迈耶公式、内能/焓/熵变的三种计算方法、四大基本过程与多变过程全表、$p\text{-}v$ 与 $T\text{-}s$ 图四象限判据及压气机分级压缩分析。
- [第4章 热力学第二定律](./第4章-热力学第二定律.md) — 第二定律两大表述与反证法、卡诺循环与卡诺定理、克劳修斯不等式、熵流与熵产、四类熵变计算模型、孤立系熵增原理与作功能力损失。
- [第5章 水蒸气及其热力过程](./第5章-水蒸气及其热力过程.md) — 常见工程设备过程图画法、水的热力学面与 $p\text{-}T$ 相图、“一点两线三区五态”、干度与湿蒸汽计算、水蒸气表查表与内插法及四大热力过程求解。
- [第6章 动力装置循环](./第6章-动力装置循环.md) — 蒸汽朗肯循环、初终参数影响规律、再热循环与抽汽回热循环定量计算、活塞式内燃机萨巴德/奥托/狄塞尔循环、燃气轮机布雷顿循环与燃气-蒸汽联合循环。
