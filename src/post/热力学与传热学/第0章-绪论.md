## 0.1 课程定位与两大支柱：工程热力学 vs 传热学

《热力学与传热学基础》由 **工程热力学（Engineering Thermodynamics）** 与 **传热学（Heat Transfer）** 两大核心板块构成。两者同属热科学（Thermal Sciences），但考察物理过程的视角截然不同。

| 对比维度 | 工程热力学（Engineering Thermodynamics） | 传热学（Heat Transfer） |
| :--- | :--- | :--- |
| **核心主题** | 热能与机械能（功）之间的**转换规律与限度** | 热量传递的**物理规律、速率计算与强化/削弱控制** |
| **关注状态** | 平衡态（Equilibrium State）与初终态之间的**能量总账** | 非平衡态（存在温差 $\Delta T$）下的**动态传输过程** |
| **时间与空间维度** | **不含时间 $\tau$**，仅关注初态 $1 \to$ 终态 $2$ 的状态参数变化 | **强依赖时间 $\tau$ 与空间坐标 $(x,y,z)$**，求解温度场 $t = f(x,y,z,\tau)$ 与热流率 $\dot{Q} = f(\tau)$ |
| **工程落脚点** | 选择合适工质、设计热力循环、计算做功量 $W$/换热量 $Q$、提高热效率 $\eta_t$ | 确定换热面积、计算冷却/加热所需时间、控制设备最高/最低工作温度 |

> [!IMPORTANT]
> **经典案例辨析：将 $1000^\circ\text{C}$ 的热钢锭投入 $20^\circ\text{C}$ 的冷油槽中**
> - **工程热力学回答的问题**：最终钢锭和油达到热平衡时的共同终温 $t_m$ 是多少？此过程中钢锭一共放出了多少热量 $Q$？（只算初终态的“能量账”，不关心快慢）。
> - **传热学回答的问题**：钢锭中心温度降到 $200^\circ\text{C}$ 需要多长时间 $\tau$？冷却过程中钢锭内部各点的温度分布 $t(x,y,z,\tau)$ 是怎样的？（算“速率与分布”）。

## 0.2 能源利用与热能的核心地位

1. **一次能源（Primary Energy）**：自然界直接存在、未经加工转换的能源，包括化石能源（煤、石油、天然气）、核能、太阳能、风能、水能、生物质能、地热能等。
2. **二次能源（Secondary Energy）**：由一次能源加工转换而成的能源产品，如电能、汽油、柴油、蒸汽、氢能等。
3. **热能的枢纽地位**：人类社会消耗的一次能源中，**约 $90\%$ 必须先转化为热能**，再通过热力设备转化为机械能或电能，或直接用于供热与工业过程。

## 0.3 热力循环的工程范式（正循环与逆循环）

在工程上，无论采用何种热力装置，热能与机械能的持续转换都必须依靠**工质（Working Fluid，如水蒸气、空气、燃气、制冷剂）**在封闭或开放回路中不断经历状态变化——即**热力循环（Thermodynamic Cycle）**。

### 1. 动力循环（正循环：热 $\to$ 功）

正循环的目的是将热能持续转化为机械功（对外输出净功 $W_{\text{net}} > 0$）。

* **典型系统一：蒸汽动力装置（朗肯循环，外燃式）**
  * **四大核心设备与流程**：
    1. **给水泵（Pump）**：将低压液态水绝热加压送入锅炉（耗功很少）；
    2. **锅炉与过热器（Boiler & Superheater）**：燃料燃烧放热，将高压水定压加热为高温高压过热蒸汽（吸热 $Q_1$）；
    3. **汽轮机（Steam Turbine）**：高温高压蒸汽在机内绝热膨胀，推动叶轮高速旋转带动发电机发电（对外做功 $W_T$）；
    4. **凝汽器（Condenser）**：做完功的乏汽排入凝汽器，向冷却水定压放热凝结回液态水（放热 $Q_2$），完成循环。
* **典型系统二：燃气轮机装置（布雷顿循环，内燃式）**
  * **三大核心设备与流程**：
    1. **压气机（Compressor）**：从大气吸入空气并绝热压缩至高压；
    2. **燃烧室（Combustor）**：喷入燃料与高压空气混合燃烧，形成高温高压燃气；
    3. **燃气轮机（Gas Turbine）**：高温高压燃气膨胀做功，一部分功用来带动同轴的压气机，其余净功对外输出（发电或推进）。

### 2. 制冷与热泵循环（逆循环：耗功移热）

逆循环通过消耗外部输入的机械功/电能（$W_{\text{in}}$），将热量从低温物体转移到高温环境。

* **四大核心部件**：
  1. **蒸发器（Evaporator）**：低温低压制冷剂从低温冷库/室内吸热蒸发（吸收制冷量 $Q_2$）；
  2. **压缩机（Compressor）**：耗功将低温低压制冷剂蒸汽压缩为高温高压蒸汽（输入功 $W$）；
  3. **冷凝器（Condenser）**：高温高压制冷剂向室外环境放热凝结为高压液体（放出热量 $Q_1 = Q_2 + W$）；
  4. **节流阀/毛细管（Expansion Valve）**：高压液体绝热节流降压降温，回到低温低压气液两相态，重新进入蒸发器。

> [!TIP]
> **工程热力学分析循环的通用四步法**
> 尽管火电厂、航空发动机、冰箱空调的机械构造千差万别，但热力学把它们高度抽象为**同一套由工质状态变化组成的四大基本环节**：
> $$\text{加压过程} \longrightarrow \text{定压/高温吸热} \longrightarrow \text{膨胀做功（或节流降压）} \longrightarrow \text{定压/低温放热}$$
> 分析任何热力系统的标准方法都是：**① 明确工质与系统边界 $\to$ ② 确定各设备进出口的工质状态参数 $(p, T, v, u, h, s)$ $\to$ ③ 对各过程列写热力学第一定律计算功与热 $\to$ ④ 用热力学第二定律评估循环效率与不可逆损失。**

## 0.4 学科研究方法

1. **经典工程热力学：宏观唯象分析法（Macroscopic Method）**
   * 不去追踪单个分子的微观位置与速度，而是直接研究由海量分子组成的宏观系统整体表现出的可测物理量（压力 $p$、温度 $T$、体积 $V$）。
   * **优势**：以热力学第一、第二定律等基本实验定律为基石，逻辑严密，结论具有极高的普适性和可靠性，不受微观模型简化的影响。
2. **传热学：连续介质假定 + 理论与实验结合**
   * 在理解微观传热机理（导热、对流、辐射）的基础上，将介质视为连续体，建立微分/积分能量守恒与本构方程（如傅里叶定律、牛顿冷却公式、斯忒藩-玻尔兹曼定律），并结合实验关联式解决复杂工程换热问题。
