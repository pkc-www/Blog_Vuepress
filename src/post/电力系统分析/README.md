电力系统分析课程的中英双语知识点，按讲整理：电力网络、稳态模型、标幺制、潮流计算与求解方法，以及电压、频率调节和经济运行。

第 9–12 讲在课件截图之外补充了代码绘图，涵盖潮流收敛、无功电压关系、调频动态与经济调度。自绘图标明模型、参数和适用范围；原始课件数值存在不一致时，保留原图并给出回代核算。第 6、9、10、11、12 讲还嵌入了网页端交互式仿真实验，可在线调参观察电压降落相量、潮流收敛与 P–U 曲线、Q–U 静态平衡、一次/二次调频动态以及经济调度。

绘图复现：`python 绘图/generate_figures.py`（需 NumPy、Matplotlib）。课件截图提取脚本为 `绘图/extract_slides.py`，原页码记录见 `绘图/slide_sources.json`。
