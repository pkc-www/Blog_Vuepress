- [第2章 导体中的恒定电流场](./第2章-导体中的恒定电流场.md) — 电流密度、欧姆与焦耳定律、静电比拟法与接地电阻。

- [第4章 时变电磁场与准静态场](./第4章-时变电磁场与准静态场.md) — 电磁感应、麦克斯韦方程组、准静态场、涡流与趋肤效应。
